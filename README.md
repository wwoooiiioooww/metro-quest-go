# 地下鉄クエスト・ルーレット 🚇

ルーレットで「行き先の駅」と「そこでやる指令」が決まる、親子のおでかけアプリ。

> next stop, どこだろう。
> ルーレットが決めた駅で降りて、決められた指令をひとつクリアする。
> それだけのことが、いつもの路線を知らない街に変えます。

小学生の子どもと保護者のために作られました。ビルド不要の静的サイト（単一HTML + PWA一式）で、GitHub Pages にそのまま置けます。

**これは個人が趣味で制作した非公式アプリです。いかなる鉄道事業者・企業・団体とも関係ありません。**

## 鉄道事業者・自治体のご担当者さまへ

このアプリは、**そのまま配っていただける状態**を目指して作っています。技術的・法務的な確認事項を先に書いておきます。

| 確認項目 | 状態 |
|---|---|
| **個人情報の収集** | **一切なし。** 氏名・年齢・位置情報・端末IDのいずれも取得しません |
| **外部との通信** | **一切なし。** 外部APIもCDNも解析タグも広告も使っていません（`fetch` 0件） |
| **データの保存先** | 利用者の端末内（`localStorage`）のみ。サーバーは存在しません |
| **端末の権限要求** | **なし。** カメラ・位置情報・通知のいずれも要求しません |
| **路線図・ロゴ・シンボル** | **不使用。** 駅データは自作のテキストリストのみで、図版素材はありません |
| **アカウント登録** | 不要。URLを開くだけで使えます |
| **アプリストア審査** | 不要。Webページなので、QRコード1枚で配布できます |
| **課金・広告** | なし |
| **通信量** | 初回のみ約50KB。以降はオフラインで動作します |

**路線名・駅名**は、行き先を示すための事実表記として使用しています。**ラインカラー**は利用者が路線を見分けるための便宜的な配色で、各社のCI/VI規定に基づく正式な色ではありません。ご指摘があれば速やかに変更いたします。

## おもな機能

| | |
|---|---|
| 🚇 ルーレット | 「行き先」「指令」「ごほうび」「対象者」の4つが回って、今日の冒険が決まる |
| 📜 指令リスト | 「商店街のアーチを見つける」「カラーマンホールを探す」など、街を見る目が変わる40種類。編集も自由 |
| ⭐ スタンプ | 指令を達成するとスタンプがたまる。ランクが上がっていく |
| 🚫 行った駅の除外 | 一度行った駅を候補から外して、まだ知らない街に当たりやすくする |
| ⚙️ 保護者せってい | 路線・エリア・回数・指令・ごほうびを全部カスタマイズできる（PINつき） |
| 📖 はじめる前に | 安全上の注意と免責。初回起動時に必ず表示されます |

**ごほうびは初期設定で「⭐スタンプ」です。** ご家庭でお使いの場合は、設定から「💰おこづかい」に変更できます。

## つかいかた

1. `index.html` / `manifest.json` / `sw.js` / アイコン2つ を、同じ階層に置いて公開します（GitHub Pages 推奨）。
2. スマホのブラウザで開き、「ホーム画面に追加」でアプリとして使えます。
3. **初回起動時に「📖 はじめる前に」が表示されます。保護者の方は必ずお読みください。**
4. ⚙️ から路線・エリア・指令を、お住まいの地域に合わせて調整してください。

データは端末内（localStorage）に保存されます。ブラウザのデータを消すと記録も消えます。

## 配布ターゲットの切り替え

`index.html` の冒頭にある1行で、初期状態でONになる事業者が決まります。

```js
const TARGET = { companies: ['metro'], strict: false };
```

- `companies` … 初期ONにする事業者（`'metro'` 東京メトロ / `'toei'` 都営 / `'jr'` JR東日本 ほか）
- `strict` … `false` なら他社も設定画面から選べます。`true` にすると他社をマスタごと除外します

## 開発

```bash
cd test && npm install && npm test
```

jsdomベースの自動テスト。**過去に実際に起きた不具合の再発防止**を主目的に書かれています。
リリース時は `index.html` の `APP_VER` と `sw.js` の `CACHE_NAME` を必ず同時に上げてください（テストで検証されます）。

**家族版 [metro-quest](https://github.com/wwoooiiioooww/metro-quest) と共通のコードベースです。バグ修正は両方に適用してください。差分の一覧は [SYNC.md](SYNC.md) にあります。**
